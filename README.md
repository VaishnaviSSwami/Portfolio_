# Vaishnavi Swami – Portfolio

Personal portfolio and notes site for a Data Engineer. A single static page: `index.html`, no build step.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Push this folder to a public GitHub repository.
2. Go to Settings > Pages.
3. Set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Your site goes live at `https://<username>.github.io/<repo-name>/` in a minute or two.
